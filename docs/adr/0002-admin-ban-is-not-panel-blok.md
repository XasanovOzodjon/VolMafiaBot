# Admin ban is not Panel blok

Panel Blok muddatsiz va global: o‘yinchini barcha guruhlarda o‘ynatmaydi, yoki guruhda o‘yinni yopadi. Admin ban faqat shu guruh, 14 kungacha, O‘yinga qo‘shilishni to‘xtatadi; chat ochiq qoladi, Telegram kick yo‘q. Ikki flagni birlashtirmaslik: moderator vaqtincha jazo qiladi, panel esa butun tizimni yopadi.
