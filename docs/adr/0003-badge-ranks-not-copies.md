# Badge is Rank, not inventory copies

Badge o‘yin narsasi kabi stack emas: o‘yinchida bitta Badge, ustida Rank (x1, x2). Do‘konda skip yo‘q — faqat keyingi Rank. Sotuv, panel Rank va avto-Shart hech qachon $ / Vcoin bermaydi; Rankda $ mukofot maydoni yo‘q (aldovchi bo‘lardi). Vcoin Rankda faqat Do‘kon narxi. Aks holda Vcoin → Badge → $ fermasi chiqadi.
