# Admin mute survives O‘yin chat restore

O‘yin tong/kun `unmute_living` / `restore_all` tiriklarni ochadi. Admin mute Telegram `until_date` ga tayanilsa ham, o‘yin tiklashi uni yeb qo‘yadi. Guruh adminining mute/ban muddati o‘yin fazasidan alohida saqlanadi; tiklashda o‘sha userlar o‘tkazib yuboriladi. O‘yin sukuti (o‘lik, tun) Admin mute ustidan ustun.
